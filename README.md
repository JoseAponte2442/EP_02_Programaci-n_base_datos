## Contexto y objetivo
NovaMarket vende productos de Redes, Seguridad y Accesorios. Se resuelven consultas con EXISTS, mantenimiento controlado (INSERT…SELECT / UPDATE / DELETE), vistas reutilizables y validación de reportes con datos de prueba.
